# Автосервис «КАРАЧИЖ» — статический сайт

Статический многостраничный сайт для ООО «Автосервис "КАРАЧИЖ"», разработанный на HTML5, CSS3 и Vanilla JavaScript (ES6+). Сайт подготовлен для последующего ручного переноса в любую CMS, включая WordPress.

## Запуск

### Через локальный сервер

Для корректной работы сайт необходимо открывать через локальный сервер. Открытие файлов напрямую через `file://` может привести к проблемам с путями и модулями JavaScript.

**Вариант 1: Python** (если установлен)
```bash
cd project/
python -m http.server 8000
```
Откройте http://localhost:8000 в браузере.

**Вариант 2: Node.js** (если установлен)
```bash
npx serve project/
```

**Вариант 3: VS Code Live Server**
Установите расширение "Live Server" и откройте `index.html` через него.

**Вариант 4: PowerShell** (встроенный)
```powershell
cd project
python -m http.server 8000
```

## Подключение реальной отправки форм

Формы в данный момент работают в демонстрационном режиме. При корректном заполнении они показывают сообщение:
> Демонстрационный режим: подключите обработчик формы перед публикацией

**Для подключения реальной отправки:**

1. **В файле `js/modules/forms.js`**:
   - Найдите метод `_onSubmit` в классе `FormHandler`
   - Замените демонстрационный вывод на реальный fetch/AJAX-запрос к бэкенду
   - Адрес обработчика настраивается через переменную `API_ENDPOINT`

2. **Альтернативно — для WordPress**:
   - В `functions.php` создайте обработчик admin-post.php или REST API endpoint
   - Обновите `action` у форм на URL обработчика
   - Адаптируйте имена полей под формат, ожидаемый обработчиком

3. **Поля, передаваемые формой**:
   - `name` — имя клиента
   - `phone` — телефон клиента
   - `source_page` — страница, с которой отправлена заявка
   - `service` — выбранная услуга (если указана)
   - `consent` — согласие на обработку данных
   - Для B2B-форм дополнительно: `company`, `transport_type`, `comment`

## Стабильные классы и data-атрибуты

### CSS-классы (BEM)

Общие:
- `.container` — контейнер с максимальной шириной
- `.section` — секция (блок) страницы
- `.button`, `.button--primary`, `.button--secondary`, `.button--outline`, `.button--large`
- `.card-grid` — сетка карточек
- `.card` — карточка
- `.placeholder-img` — изображение-заглушка

Хедер:
- `.header`, `.header__inner`, `.header__logo`, `.header__nav`, `.header__nav-list`, `.header__nav-item`, `.header__nav-link`
- `.header__nav-link--active` — активный пункт меню
- `.header__phone` — кликабельный телефон
- `.header__menu-toggle` — кнопка мобильного меню

Футер:
- `.footer`, `.footer__grid`, `.footer__col`, `.footer__title`, `.footer__links`, `.footer__bottom`

Формы:
- `.form`, `.form--callback`, `.form--b2b`
- `.form__status` — контейнер статуса отправки
- `.form__field` — поле формы
- `.form__label`, `.form__input`, `.form__textarea`, `.form__select`
- `.form__error` — ошибка поля
- `.form__consent` — чекбокс согласия
- `.form__conditional` — условное поле (B2B)

Модальное окно:
- `.modal`, `.modal__overlay`, `.modal__content`, `.modal__header`, `.modal__close`, `.modal__body`

FAQ:
- `.faq`, `.faq__item`, `.faq__question`, `.faq__answer`

Фильтр услуг:
- `.filter`, `.filter__tab`

Цены:
- `.price-table`, `.price-table__row`, `.price-table__header`

### data-атрибуты

- `data-placeholder="true"` — отмечает заглушку, требующую замены
- `data-form="callback"` — идентификатор формы
- `data-form-status` — контейнер для сообщений формы
- `data-error-for="name|phone|consent"` — привязка ошибки к полю
- `data-modal-open="callback"` — открыть модальное окно
- `data-modal-close` — закрыть модальное окно
- `data-category="passenger|truck"` — категория услуги для фильтра
- `data-filter="all|passenger|truck"` — значение фильтра
- `data-analytics="event_name"` — событие для аналитики
- `data-b2b-trigger` — триггер для показа условных полей B2B

## Замена изображений

1. **Генерация изображений:**
   - Используйте промпты из `/prompts/image-prompts.md` для генерации через Midjourney, DALL-E или аналоги
   - Каждый промпт содержит требования к реалистичности, палитре и отсутствию текста/логотипов

2. **Размещение изображений:**
   - Исходные изображения поместите в `/images/optimized/`
   - Замените ссылки в атрибутах `src` элементов с классом `.placeholder-img`
   - После замены изображений удалите класс `placeholder-img` и текст-заглушку внутри

3. **Форматы и размеры:**
   - Рекомендуемые форматы: WebP (основной), JPEG (запасной)
   - Для hero-изображений: 1200×675 px
   - Для карточек услуг: 600×400 px
   - Для портфолио: 800×534 px
   - Используйте `srcset` и `<picture>` для адаптивных изображений
